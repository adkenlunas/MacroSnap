MacroSnap

MacroSnap is a nutrition tracking app that extracts nutritional information from a photo of a food product's Nutrition Facts label. Instead of manually entering values, users can capture a label and get its key nutritional data in a structured format.

Features

Nutrition Label Scanning — Capture or upload a photo of a Nutrition Facts label.

Macro Extraction — Extract calories, protein, carbohydrates, and fats from the label.

Structured Nutrition Data — Convert label information into organized, easy-to-read nutritional values.

Fast and Convenient — Reduce the need for manual nutrition data entry.

Additional features will be documented as development progresses.

How It Works

Take a photo of a product's Nutrition Facts label or upload an existing image.

MacroSnap processes the image and extracts the nutritional information.

Review the extracted data and its macronutrient values.

Note: Accuracy depends on image quality, label readability, and the extraction method used. Always verify extracted values against the original label.

Tech Stack

Frontend: React

Backend: Node.js and Express

Database: PostgreSQL

Image Processing: Sharp.js

Data Extraction: Tesseract.js
